# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Cargo workspace of 8 Substreams packages (`polymarket-*`) that extract Polymarket
events on Polygon, plus `polymarket-substreams-common` — a plain shared helper crate
(no wasm target, no manifest). All 8 packages are released in lockstep at the same version.

## Build / test / lint

- Build one package: `cd polymarket-<name> && substreams build` (runs `buf generate` then a cargo wasm release build).
- Build all: `make build-all`.
- Test: `cargo test` at the repo root. **CI does not run tests** — run them locally.
- Lint: `cargo clippy --workspace -- -D warnings` (clippy is installed via `rust-toolchain.toml` but **not run in CI**; the pre-commit hook runs it).
- CI (`.github/workflows/release.yml`) triggers **only on `v*` tag push** — it builds + publishes. There is no PR/branch CI.

## Generated code — do not hand-edit

`src/pb/` is generated by `buf generate` (per-package `buf.gen.yaml`); `src/abi/` is
generated by `build.rs` from `abi/*.json`. Both are committed to git but are
regenerated by `substreams build`. Edit the `.proto` schema or the ABI JSON — never
the generated `.rs` files.

## Substreams conventions (match the existing packages)

- Filter logs by 20-byte address constants compared directly: `const X: [u8;20] = hex_literal::hex!("…"); if log.address == X`. Never compare addresses as hex strings (~25× slower).
- `map_all_events` does a **single pass** over `blk.logs()`, classifying each log via an if/else-if chain into category structs.
- **No `.unwrap()` / `.expect()` / `panic!` in handlers.** Decode with `if let Ok(ev) = Event::decode(log.log)` and skip on error. (`.expect()` is fine inside `#[cfg(test)]`.)
- Use the shared helpers from `polymarket-substreams-common` (`bigint_to_string`, `bigint_to_u32`, `format_address`, `build_tx_context`) — don't re-implement them per package.
- Every event proto carries `tx: Option<TransactionContext>`, populated via the package's `build_transaction_context` wrapper.

## Running against the chain

Needs `substreams auth` first (API key from thegraph.market). Endpoint: `polygon.streamingfast.io:443`.

## Releases & new packages — use the skills

Versions bump across ALL manifests in lockstep → one commit → tag `vX.Y.Z` (the tag
push triggers the publish CI). These repeatable workflows live as project skills in
`.claude/skills/` — prefer them over ad-hoc steps:
`releasing-substreams-packages`, `adding-substreams-package`,
`running-substreams-validation`, `warming-substreams-indexes`, `syncing-substreams-docs`.
